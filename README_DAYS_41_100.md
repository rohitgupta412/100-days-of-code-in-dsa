# 100 Days of DSA - Days 41-100

## Overview
Yeh repository Day 41 se Day 100 tak ke DSA questions ko cover karti hai. Har day ke liye alag folder hai jisme C language mein solutions hain.

## Folder Structure
```
Day41/ - Queue Using Linked List
Day42/ - Reverse Queue Using Stack
Day43/ - Binary Tree Level Order Traversal
Day44/ - Binary Tree Traversals (Inorder, Preorder, Postorder)
Day45/ - Height of Binary Tree
Day46-50/ - Tree Problems
Day51/ - Lowest Common Ancestor in BST
Day52-60/ - Advanced Tree Problems
Day61-68/ - Graph Representation and Traversal
```

## Topics Covered

### Stack & Queue (Days 41-42)
- Queue implementation using Linked List
- Reverse Queue using Stack
- Task Scheduler
- Find Median from Data Stream

### Trees (Days 43-60)
- Binary Tree Construction and Traversal
- Height and Depth calculations
- BST operations
- Lowest Common Ancestor
- Tree Views (Left, Right, Top, Bottom)
- Symmetric and Mirror Trees

### Graphs (Days 61-80)
- Graph Representation (Adjacency Matrix/List)
- DFS and BFS Traversal
- Cycle Detection
- Topological Sort
- Shortest Path Algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall)
- Minimum Spanning Tree (Prim's, Kruskal's)

### Sorting & Searching (Days 81-100)
- Binary Search and variations
- Merge Sort
- Quick Sort
- Counting Sort
- Bucket Sort
- Advanced problems on sorting
